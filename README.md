# 🚀 Ramaera Hosting – FastAPI Backend

Ramaera Hosting is a **server provider web application backend** built using **FastAPI**.  
It provides secure, scalable APIs for managing users, servers, hosting plans, payments, and subscriptions.

---

## 🏗️ Tech Stack

- **Backend Framework:** [FastAPI](https://fastapi.tiangolo.com/)
- **Database:** PostgreSQL (via SQLAlchemy ORM)
- **Authentication:** JWT-based Authentication
- **Task Management (optional):** Celery / Background Tasks
- **Payment Gateway:** Razorpay Integration
- **Environment Management:** Python-dotenv
- **Deployment:** Docker / Uvicorn / Gunicorn
